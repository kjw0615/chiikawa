# 작은 상영관 — Node.js 프로토타입

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다.

```powershell
npm start
```

http://localhost:3000 접속. 포트 변경: `$env:PORT=3001; npm start`.

- 공식 YouTube 플레이어로 제공된 영상과 재생목록 재생
- 플레이어에서 반환하는 재생목록으로 목록 확장, 이전/다음 영상 이동
- 제목/목록 번호 검색, 시청 완료 표시와 필터
- localStorage에 3초마다 재생 위치 저장, 다시 방문하면 이어 보기
- 모바일 화면 지원, 저장소 및 영상 연결 실패 안내

예시 영상 외에는 실제 회차를 추정하지 않고 재생목록 순서로 표시합니다. 재생목록의 모든 제목을 가져오는 YouTube Data API 연동은 포함하지 않았습니다. 목록 반환이 제한되면 예시 영상과 유튜브 재생목록 링크를 제공합니다. API 키는 필요하지 않습니다.

한국어 번역은 아직 포함하지 않았습니다. 일본어 원문과 시간 정보를 확보한 뒤 번역 영역을 연결해야 합니다. 외부 자막 파일을 공식 플레이어에 주입하는 기능은 없습니다.

시청 기록은 같은 사이트 주소·브라우저·프로필에만 보관됩니다. 다른 기기로 동기화되지 않으며, 사이트 데이터를 지우면 사라집니다. 영상 재생에는 인터넷 연결과 업로더의 외부 재생 허용이 필요합니다.

서버는 로컬 컴퓨터(127.0.0.1)에만 바인딩합니다. 배포하지 않은 로컬 프로토타입입니다.

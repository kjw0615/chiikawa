# 작은 상영관 — 치이카와 한국어 더빙판

Node.js 18 이상. 외부 npm 패키지나 API 키 없이 실행합니다.

```powershell
npm start
```

http://localhost:3000 접속. 포트 변경: `$env:PORT=3001; npm start`.

## 기능

- 첫 접속은 첨부된 연못 이미지의 대기 화면. 재생 버튼을 누를 때만 YouTube API와 플레이어를 로드합니다.
- 한국어 더빙 재생목록 `PLRU7nJfHLAe8`, 시작 영상 `kzAfNg6pAvI`.
- 셀렉트 박스로 영상 선택, 이전/다음 이동, 대기 화면 복귀.
- 재생 위치를 3초마다 localStorage에 저장. 재방문 시 자동 재생 없이 이어 보기 버튼을 제공합니다.
- 시청 완료 표시와 기록 초기화. 기존 일본어판 기록과 별도 저장합니다.
- 두 번째 첨부 이미지를 전체 페이지 배경으로 사용한 크림색·연두색 디자인 및 모바일 배치.
- 자막 및 번역 UI는 현재 제외했습니다.

`public/episodes.js`는 2026-10-27 공개 재생목록에서 확인한 영상 248개의 ID와 제목입니다. 실제 제목을 유지하므로 목록에 없는 119화·240화를 임의로 만들지 않았습니다. 새 영상의 제목과 초기 선택 목록을 갱신하려면 이 파일을 업데이트하세요. 플레이어가 반환한 새 영상 ID는 현재 방문 중 목록에 추가됩니다. 대규모 재생목록에서 플레이어가 일부만 반환해도 기존 전체 목록을 유지합니다.

`public/assets/waiting-pond.png`와 `cream-friends.png`는 사용자가 제공한 이미지입니다.

영상 재생에는 인터넷과 업로더의 외부 재생 허용이 필요합니다. 브라우저가 자동 재생을 제한하면 플레이어에서 재생 버튼을 눌러야 합니다. 저장 기록은 같은 사이트 주소·브라우저·프로필에만 보관되며 다른 기기로 동기화되지 않습니다.

서버는 127.0.0.1에 바인딩된 로컬 프로토타입입니다. 검사는 `npm run check`로 실행합니다.
